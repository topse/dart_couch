# dart_couch_widgets Project Guidelines

Flutter widgets for [dart_couch](../dart_couch/). The core principles and requirements in `../dart_couch/CLAUDE.md` apply here as well.

## Changelog

Entries in `CHANGELOG.md` are short headlines, one line per change (e.g. `* bugfix: ReplicationStateProxyWidget opened before initial sync`). Details belong in code comments or the README, not in the changelog. New entries go under `## Unreleased` at the top.
